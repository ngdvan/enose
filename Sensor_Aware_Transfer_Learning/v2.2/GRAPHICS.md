# v2.2 full-revision graphics

The complete bilingual export is in [`figure/`](figure/README.md): `en/` contains the exact English images embedded in the authoritative manuscript, while `vn/` contains matching Vietnamese editions at identical pixel dimensions. Regenerate it with `scripts/generate_bilingual_manuscript_figures.py`.

The authoritative graphics accompany `author_review/full_revision_001/`. Earlier `paper_draft/` graphics are superseded and were archived outside this repository.

Regenerate Figures 3 and 4 from the repository root:

```powershell
python Sensor_Aware_Transfer_Learning/v2.2/scripts/generate_graphics.py
```

This writes the six PNG/PDF/SVG figure files without rebuilding manuscripts or rerunning training. PNG exports use 400 dpi. The builder now supports generating these files when the output directory or files are absent.

For the supplementary figure, run `scripts/analyze_seed_stability.py`. To embed changed graphics, follow the full document build and verification sequence in [README_MAJOR_REVISION.md](README_MAJOR_REVISION.md), then render fresh PDFs and run the render checker. The existing final documents and graphics are preserved by the cleanup.
